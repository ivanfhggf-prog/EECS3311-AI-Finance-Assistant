# EECS3311 Course Project — AI Personal Finance Assistant

An AI agent that imports bank transactions, categorizes them, tracks budgets and savings goals, detects unusual and recurring spending, answers natural-language questions about spending, and generates summaries and saving suggestions. Available through a GUI and a CLI.
